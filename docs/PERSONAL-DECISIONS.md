开发分支 `feat/usable-four-20261030`，2026-10-31。

快速输入保留常见耗时、单程费用、上班时间和月通勤天数。三点假设在路线旁明确，尾部阈值与细图按需展开，仍使用原有稳定路线种子的模拟与个人记录重采样。

首要结果为每月多花、节省小时与每省一小时额外费用；相同时间不显示无穷大，更慢或无额外花费分别说明。结果旁可直接校准对应路线，不改另一条。估计输入、个人记录及模型内范围各有标记。

用户明确选择后，在独立 `commute:decision:v1` 保存输入、模型版本、结果、理由和时间。旧 v2 路线草稿兼容，没有选择时显示尚未选择。改参数保留旧快照但标为待重新确认。数值留空、编辑未提交、无效和重算时禁用当前选择与导出。复制摘要与 JSON 均来自已确认快照；存储不可用仍可在页内操作和导出。

验证：6项既有边界和3项决策检查通过。浏览器完成自定义耗时、单条记录校准不改其他路线、选择、空值阻止导出、参数更新后重新确认、JSON；三种宽度无横向溢出。没有地图或实时交通调用，风险不等于未来准点率。
